# cburnett chess pieces

The 12 SVGs in this folder are the "cburnett" chess piece set by Colin M.L. Burnett, as used by lichess.org.

- **Author:** Colin M.L. Burnett (https://en.wikipedia.org/wiki/User:Cburnett)
- **Original:** Wikimedia Commons, "SVG chess pieces" (`Chess_*t45.svg`), tri-licensed by the author under GFDL, BSD and GPL. We use them under the BSD licence option.
- **Extracted from:** the npm package `@lichess-org/pgn-viewer` 2.6.4, file `scss/_chessground.cburnett.css` (base64-encoded background images, decoded unchanged). lichess lists the set as "Colin M.L. Burnett, GPLv2+" in lila's `COPYING.md`.
- **File names** follow lichess: colour (`w`/`b`) + piece (`P N B R Q K`).
